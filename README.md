# learn-self-media

自媒体内容研究与实践仓库。

## 目标

围绕自媒体内容生产建立可复用的方法论、案例库、模板与实验记录，重点研究：

- 选题与热点判断
- 标题与封面点击率
- 开头 Hook 与前 30 秒留存
- 信息密度与叙事节奏
- 情绪、冲突与梗点设计
- 剪辑、字幕、音效与视觉重置
- 完播率、互动率、转发率
- 平台推荐与内容复盘

## 子项目

### [learn-self-media-viral-video](./learn-self-media-viral-video/)

专门研究“爆款视频是怎么做出来的”，通过拆解真实热门视频，总结可复用的视频结构、脚本模板、剪辑方法和复盘体系。

## 工作方式

1. 找到高热视频样本。
2. 记录基础数据与发布时间。
3. 按秒拆解标题、封面、Hook、结构、高潮、结尾。
4. 抽象为可复用的方法论。
5. 用模板重新创作一个同结构、不同内容的作品。
6. 发布后记录数据并复盘。

> 研究重点是结构和方法，不直接复制他人的文案、镜头或受版权保护的表达。
