# learn-self-media-viral-video

专门研究如何制作高点击、高留存、高完播、高互动的爆款视频。

## 研究问题

我们不只问“这个视频为什么火”，而是把问题拆成：

1. **为什么用户会点进来？** —— 选题、标题、封面、热点势能。
2. **为什么前 15 秒没划走？** —— Hook、承诺兑现、冲突与悬念。
3. **为什么能继续看到 1 分钟？** —— 背景压缩、信息密度、节奏。
4. **为什么能看到结尾？** —— 递增式爆点、章节重置、高潮后置。
5. **为什么愿意点赞评论转发？** —— 情绪、立场、梗、讨论空间。
6. **为什么平台继续推荐？** —— 点击、留存、完播、互动形成正反馈。

## 核心模型

```text
爆款势能 = 选题势能 × 点击率 × 前30秒留存 × 完播率 × 情绪/梗密度 × 互动传播 × 平台放大
```

不是每个视频都要把所有项做到极致，但至少要明确：当前作品主要靠哪几项赢。

## 第一阶段研究重点

- B站 3～8 分钟热点吐槽视频
- 前 5 秒 / 15 秒 / 30 秒留存设计
- “一层比一层更大”的递增叙事
- 每 3～6 秒一次视觉变化
- 每 20～30 秒一次注意力重置
- 标题承诺与开头兑现
- 章节卡、表情包、影视梗、音效的使用
- 高争议事件如何区分“已确认事实”和“单方叙事/网传”

## 评价标准

每个案例至少给以下维度打分（10分制）：

| 维度 | 含义 |
|---|---|
| Topic | 选题势能 |
| CTR | 标题/封面点击潜力 |
| Hook | 前15秒留存能力 |
| Density | 信息密度 |
| Escalation | 爆点递增能力 |
| Visual | 视觉更新频率 |
| Emotion | 情绪强度 |
| Meme | 梗与二创能力 |
| Completion | 完播潜力 |
| Interaction | 评论/弹幕/转发潜力 |
