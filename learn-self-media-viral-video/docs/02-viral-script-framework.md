# 4～5分钟热点视频脚本框架

## 0:00～0:15 — Hook

目标：不解释背景，连续扔 4～7 个最诱人的关键词。

原则：

- 不寒暄。
- 不自我介绍。
- 不一次讲完答案。
- 先兑现标题，再制造新的信息缺口。

## 0:15～0:50 — Context

30～40秒内交代：

- 谁
- 什么事
- 为什么现在火
- 哪部分是已确认事实

## 0:50～1:40 — 第一层异常

给一个足够强、但不是全片最大的事件。

## 1:40～2:10 — 反差

通过数字、身份、行为或前后差异制造笑点。

## 2:10～2:50 — 标题核心事件

正式兑现标题中的核心承诺。

## 2:50～3:40 — 最大爆点

把一个标题没有完全说透、但更刺激的点后置。

这是维持 60%～80% 时长留存的重要区间。

## 3:40～4:20 — Reaction / Reversal

- UP主观点
- 当事人回应
- 事实边界
- 反转

## 4:20～4:40 — Exit

- 一句高密度总结
- 一个最后梗
- CTA
- 立即结束

## 写作检查

每句话至少承担一个功能：

- 新信息
- 新冲突
- 新笑点
- 新悬念
- 新情绪
- 新证据

如果一句话六项都没有，优先删掉。
